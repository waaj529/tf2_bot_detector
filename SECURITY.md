# Security Policy

## Supported Versions

Only the latest release of TF2 Bot Detector receives security updates. If you discover a vulnerability, please update to the latest version to see if it has already been addressed.

| Version | Supported |
| ------- | --------- |
| Latest  | :white_check_mark: |
| < Latest| :x:        |

## Reporting a Vulnerability

We take the security and integrity of TF2 Bot Detector seriously. Because this tool handles RCON connections and monitors game memory/logs, security is vital.

If you find a security vulnerability, please **do not** open a public issue on GitHub. Instead, report it through one of the following secure channels:

1. **Private Discord Contact**: Direct message a project administrator on the [Official Discord Server](https://discord.gg/W8ZSh3Z).
2. **GitHub Private Vulnerability Reporting**: If enabled on the repository fork, use the "Report a vulnerability" button under the Security tab.

Please include the following details in your report:
- A clear description of the vulnerability.
- Steps to reproduce or a proof of concept (PoC).
- Potential impact of the exploit.

We will acknowledge receipt of your report within 48 hours and work with you to coordinate a security patch and release. Thank you for helping keep TF2 Bot Detector safe for everyone.
